## Матриця нефункціональних вимог (NFRs)

| ID | Вимога | Метрика |
|---|---|---|
| NFR-PER-01 | Затримка `roll()` | p95 ≤ 150 мс при 200 RPS |
| NFR-PER-02 | Затримка верифікації | p95 ≤ 100 мс (CDN-кеш), ≤ 500 мс без кешу при 500 RPS |
| NFR-SCL-01 | Масштабування API | Stateless-репліки, приріст ≥ 1.8× при 2 репліках |
| NFR-SEC-01 | Захист каналів | TLS 1.3 |
| NFR-SEC-02 | Автентифікація | API-ключі (SHA-256 хеш); кабінет – OAuth 2.0 / OIDC, JWT |
| NFR-SEC-03 | Захист ключів | Ed25519 у HashiCorp Vault, `exportable = false` |
| NFR-SEC-04 | Комплаєнс | OWASP API Security Top 10 (2023), ASVS L2, GDPR |
| NFR-REL-01 | Доступність | ≥ 99.9% на місяць |
| NFR-REL-02 | Цілісність | 0 пропущених / дубльованих nonce під час тестів відмов |
| NFR-REL-03 | Відновлення | RPO ≈ 0, RTO ≤ 1 год |
| NFR-INF-01 | Інфраструктура | Docker Compose, GitHub Actions |
| NFR-COR-01 | Рівномірність | χ² на 10^7 значень, α = 0.05 |
